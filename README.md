# Openclassrooms troisieme projet HTML CSS

Création d'un site en mobile first, depuis un maquette figma : https://www.figma.com/design/t4449fzDnwGYmzuwQdu87V/Maquettes-Ohmyfood--mobile-et-desktop-?node-id=0-1&p=f

premier site créer sans auccune base de code fournis.
Un index contenant des cartes de restaurant qui amenent chacunes a une page, ces pages ont le meme type de contenue : menu du restaurant cliqué.
Premiere utilisation de SASS à la place de css simple, et premiere utilisation d'animation.

Ce projet permet deja de voir que d'autres outils existe et permette de repondre a certains problemes ou juste rendre certaines chose plus facile/lisible, comme SASS ou SCSS par rapport à css : Permet la création de variables et d'organisé les fichiers plus proprement par exemple.
Mais ce projet permet aussi de nous faire remarquer un probleme : pour un site comme celui ci, ou chaque restaurant vont avoir une page avec une structure identique, avec seulement les element qui change (titres, images, textes, etc...) créer une page pour chaque restaurant devient tres vite long, et pour des changement future sela créerais enormement de travails selon le nombre de restaurant... ce probleme sera resolu dans un futur projet, via react
